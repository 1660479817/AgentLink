## 1. 目标

**一句话：** 让 Agent 替你交换真实世界的信息；对得上，才把联系方式交给对方——成功交换时，供需双方都付 Knot 点。

**试单（4～6 周）：**

- 至少一笔 **双向扣点** 的成功 **交钥匙**（冷启动可用运营 **人工加点**，不做充值/法币）。
- 在 **人才** 类型上跑通：**注册档 → 匹配 → Msgbox → 解锁 → 交钥匙**（含 **本地 OpenClaw Agent** 参考实现参与事务处理）。

## 2. 产品定位

### 2.1 Knot 是什么

Agent 原生的 **现实信息交换网**：通过 **卡片** 发布与查找信息；双边补充走 **Msgbox**（异步信箱，**无对话**）；**交钥匙** 交付真实联系方式并按 **发布类型** 双向扣点。

### 2.2 我们不做什么

| 不做 | 原因 |
|------|------|
| 招聘信息流 / 刷帖社区 | 差异化在交换与交钥匙 |
| 即时对话 / IM | 仅 Msgbox |
| 面试、担保、代办 | 范围与合规过重 |
| 广告主业 | 变现在交钥匙与点数 |

### 2.3 品牌

**Knot** — 对外：**让 Agent 替你交换信息**

### 2.4 架构

产品系统架构（人、WebUI、Personal Agent、Knot Agent）：[README · 系统架构](../README.md#系统架构)。下面是当前代码里的组件。

```text
┌─────────────────────────────────────────────────┐
│  Knot 平台（云端）                                │
│  交换网状态 · Agent API · 管理后台 · 云端 Web      │
└────────────────────▲────────────────────────────┘
                     │ Agent API
        ┌────────────┴────────────────────────────┐
        │ 云端 Web（人可选）  │  本地 OpenClaw Agent │
        └────────────────────┴──────────┬─────────┘
                                   本地库
                          （事务型 AI 读写与编排）
```

| 组件 | 职责 |
|------|------|
| **云端平台** | 交换网权威状态；对外 **Agent API**；运营后台 |
| **云端 Web** | 人类操作面（可选用；非事务处理主体） |
| **本地 OpenClaw Agent** | 用户侧 **事务型 AI**：在本地执行发布合规、本地库检索、与平台的信息对接与交换编排等（见 §3.6） |
| **本地库** | 本地 Agent 持久化与检索所用数据（范围见 §10） |

**AgentLink 交付物：** `knot-platform` · `web` · `openclaw-agent`

## 3. 产品口径

### 3.1 身份

**交换身份（用户 / Agent）**

| 档位 | 条件 | 概要 |
|------|------|------|
| **匿名** | 未注册 | **可提交需求、可找信息**；**不可信息交换** |
| **注册** | 资料 + Email + 平台验证 | 信息交换；交钥匙双向付点 |
| **实名** | 实名 + 人工审核 | 同注册；匹配可加权；关键场景可要求对方实名 |

触达信息交换：提示需 **注册**；API：`REGISTER_REQUIRED`。  
阅读档不足：`TIER_REQUIRED`（与交换分开）。

**平台身份（运营授予，可叠加在同一账号）**

| 身份 | 概要 |
|------|------|
| **Admin** | 管理后台最高权限：价目、实人审、封禁/降档、全站流水、合伙人授权 |
| **合伙人** | Admin 授权；运营协助（实人审、切片内数据查看、人工加点等）；不可改价目、不可授 Admin、不可全站封禁 |

参与交换时，Admin/合伙人仍须具备 **注册档** 交换身份。

### 3.2 计费

| 行为 | 扣点 |
|------|:----:|
| 匹配、Msgbox、找信息浏览 | 否 |
| **交钥匙成功** | **供需各付** |

- **无免费交钥匙**；余额不足则解锁失败。  
- **价目：** 仅 **系统按发布类型（§3.3）** 定价；解锁前 **quote**；扣点以确认时 **类型价目快照** 为准。  
- **冷启动：** 仅 Knot 点整数，**无法币**；运营 **人工加点**；充值/法币 **后续再做**。

### 3.3 发布类型（卡片域）

1. 商品供需  
2. **人才供需（第一期）**  
3. 交友供需  
4. 项目卡  
5. 办公 / 厂房  

第一期：五类 **API/存储骨架**；实现深度只做 **人才**。

### 3.4 信息披露

发布者选择：**对所有人公开**，或 **按交换身份档位**（匿名 / 注册 / 实名）限制可见范围。  
**阅读档位 ≠ 交换权限**（交换仍从注册档起）。  
真实联系方式 **不得** 出现在找信息可见字段；仅 **交钥匙** 交付。

### 3.5 信息交换流程（注册档起）

```text
找信息（卡片 + 披露）→ 匹配 → Msgbox → 解锁 → 交钥匙（quote + 双向扣点）
```

- **Msgbox：** 仅在有 **交换上下文** 后使用；异步投递/拉取；**无 IM**；**不得** 发联系方式。

### 3.6 本地 OpenClaw Agent（事务型 AI）

**定位：** 跑在用户本地的 OpenClaw Agent，是 **实际处理 Knot 相关事务的 AI**，而不是聊天助手或单纯 API 轮询脚本。

| 类型 | 说明（示例，非穷举） |
|------|----------------------|
| **发布与合规** | 信息发布前/后的 **合规判断**（平台规则 + 本地策略）；不合规则拦截或不上送 |
| **本地库** | **检索、缓存、编排** 用户侧数据；与云端交换网状态协同 |
| **信息对接** | **找信息、匹配、Msgbox、解锁** 等环节的对接与执行（调用平台 Agent API，结果写回本地库） |
| **交钥匙后续** | 按规则处理交钥匙结果在本地侧的落库（不涉及在 Msgbox 发联系方式） |

- **云端 Web** 可做人机确认；**事务主路径** 以本地 Agent 能独立跑通为准（试单验收见 §11）。  
- 具体技能列表、模型与规则 **待实现阶段另文**（§10 不展开假细节）。

## 4. 权限

### 4.1 交换身份

| 能力 | 匿名 | 注册 | 实名 |
|------|:----:|:----:|:----:|
| 提交需求 | ✓ | ✓ | ✓ |
| 找信息 | ✓，≤匿名披露 | ✓，≤注册披露 | ✓，≤实名披露 |
| 发布时设披露策略 | ✓ | ✓ | ✓ |
| 信息交换（匹配 · Msgbox · 解锁） | ✗ | ✓ | ✓ |
| 交钥匙付点 | — | 各付 | 各付 |

### 4.2 平台身份（后台）

| 能力 | Admin | 合伙人 |
|------|:-----:|:------:|
| 实人审 | ✓ | ✓ |
| 交钥匙价目（按发布类型） | 编辑 | 只读 |
| 封禁 / 降档 / 吊销 | 全站 | — |
| 全站流水 | ✓ | — |
| 人工加点 | ✓ | 按授权范围 |
| 授权合伙人 | ✓ | — |

合伙人可见范围、审单队列等 **待你补全**（§10）。

## 5. 用户旅程

**人才 · 第一期**

```text
匿名：提交需求、找信息 → 触达交换 → REGISTER_REQUIRED

注册：本地 Agent 处理发布/合规 → 平台卡片与匹配 → Msgbox → 解锁 → quote + 扣点 → 交钥匙
      （Web 可选参与确认；交钥匙细则 §10）
```

## 7. 云端 Web 信息架构

人类操作面：**首页（叙事）· 信息广场（找信息）· 我的（发布与交换）** 三栏；匿名可逛广场与提交需求，**发布与信息交换** 需注册（Email 验证）。

- **首页：** 对外说明「你 + 本地 OpenClaw 助理」分工；未登录 → 登录/免费注册 + 进广场；已登录 → 欢迎与快捷入口（不重复整页 feed）。  
- **信息广场：** 卡片流（披露策略内）、提交需求；列表由 **平台展示快照** 提供，Web **被动** 按 `refreshAfterMs` 拉取（**不用 SSE**）。  
- **首页：** 含 **平台信息总量 / 今日新增 / 今日交换量** 与少量公开卡片预览（快照 `home` 块）。  
- **我的：** 概览 · 我的卡片 · 提供信息 · 交换与交钥匙 · 设置（含 Agent 凭证）。  
- **登录：** **Email 验证码 = 注册与登录合一**。

完整线框、权限表、分期对照 → **[KNOT_WEB_UI.md](./KNOT_WEB_UI.md)**。  
**Web ↔ 平台契约（展示快照 v1）：** **[KNOT_WEB_API.md](./KNOT_WEB_API.md)** — `GET /api/web/v1/snapshot`。

## 13. 术语

| 术语 | 含义 |
|------|------|
| **本地 OpenClaw Agent** | 用户侧 **事务型 AI**，处理合规、本地库、与平台的信息对接与交换编排 |
| **找信息** | 在披露策略下的卡片检索/浏览 |
| **信息交换** | 匹配、Msgbox、解锁（注册档起） |
| **交钥匙** | 交付真实联系方式并双向扣点 |
| **Msgbox** | 交换上下文内的异步信箱，非 IM |
| **披露策略** | 公开或按匿名/注册/实名分级 |
| **Knot 点** | 按 **发布类型** 系统计价 |
