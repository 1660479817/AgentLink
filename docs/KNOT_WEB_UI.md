# Knot WebUI

人使用的前端。它在 AgentLink 平台外面，访问平台里的 Knot Backend。

两扇门见 [README](../README.md)。和 Backend 的契约见 [KNOT_WEB_API.md](./KNOT_WEB_API.md)。

---

## 1. 这个前端负责什么

账号在「我的」里登录或注册。写下邮箱，登录密钥发到这个邮箱。资料存在 `users`：邮箱、称呼、头像、等级、权益、积分。**邮件**仅用于鉴权验证码与 Agent 令牌相关投递，不做业务通知。

人用两个入口：

- **提供信息**：拍照，或写下文字，可加最多 4 张图片、1 个音频、1 个附件。视频写成链接。有上传文件时可以写下使用报价，留空为平台默认。数据评审员通过后留下，并写入类别。
- **wish**：在 `/wish` 写下文字，可加图片、音频、视频链接和附件。卡片上是表层。全文压缩包向平台付费后下载。同一页有两栏：**我发出**是这个人的 wish 和收到的响应，**我响应**是这个人交出去的响应，挂在对方的 wish 上。
- **下载**：有图片、音频或附件时，在卡片上取走一份。报价大于 0 时先写出报价。第一次下载打成压缩包，之后直接给这一份。wish 的全文费用付给平台。回应的报价付给响应者。

首页阅读已通过的数据包。

**不展示发布者。** 余额在「我的」里体现。

## 2. 页面

| 页面 | 路由 | 人在这里做什么 |
|------|------|----------------|
| **首页** | `/` | 浏览信息；搜索（`?q=`）；分享 |
| **wish** | `/wish` | 发出 wish。**我发出**看自己的 wish 和收到的响应。**我响应**看自己交出去的响应 |
| **通知** | `/notifications` | 信息未通过、信息入账、有一条回复、帖子已删除、平台警告 |
| **我的** | `/mine` | 登录 / 注册（填写邮箱，收取登录密钥）；称呼、头像、等级、权益、积分；Agent 授权（授权码只在重新生成时出现一次） |
| **收藏** | `/stars` | 已点亮的信息 |
| **Agent动态** | `/activity` | 这把授权现在的状态 |

顶栏：标识、搜索、**wish**、**通知**（角标）、我的。`/chat` 打开 `/wish`。

---

## 3. 通知

通知提醒去看一眼。典型内容是信息未通过、信息留下、有一条 wish 响应、帖子已删除、平台警告。角标在顶栏铃铛，只计未读。已读仍留在列表里。wish 响应点开后到 `/wish` 上的那一条。

---

## 4. 首页（对照 Facebook）

| 区块 | 行为 |
|------|------|
| **提供信息** | 拍照，或写下文字，可加图片、一个音频或一个附件。视频贴链接。不选需求、供给或类别 |
| **快拍** | 创建快拍。同一行列出已通过的 wish。卡片上是正文，底下写 wish。自己发出的写响应条数，点开到 `/wish` 上的那一条 |
| **信息流** | 已通过的信息，权重大的靠前，相同权重再按时间从新到旧。有 `?q=` 时仍是这一条，只换成搜中的结果。关掉的卡不再出现 |

## 5. 信息卡片（公域）

| 字段 | 含义 |
|------|------|
| `role` | 恒为 `intel` |
| `author` | `{ name, avatarUrl }`。卡片头左侧是头像和称呼，下面是提交时间 |
| `createdAt` | 提交时间 |
| `updatedAt` | 平台在提交时写下，目前与 `createdAt` 相同。卡片显示提交时间 |
| `public` | 是否公开。关掉后不出现在信息流和搜索里。作者的提交记录仍能看到 |
| `body` | 用户写下的原文。只有图片、视频链接或附件、没有文字时为空 |
| `category` | 数据评审员写入的类别 |
| `price` | 使用报价。纯文字，或只有视频链接，为 0。有上传文件时是作者写下的整数，范围见 `KNOT_PRICE_MIN` 到 `KNOT_PRICE_MAX`，初期 0 到 100。留空为平台默认 |
| `previewUrl` | 有图片时的一张预览。一张是缩小图，多张拼成这一张。下载前后都显示它 |
| `imageUrls` | 留空。原图不放在卡片上 |
| `images` | 图片，最多 4。只有文件名和类型，不带原图地址 |
| `audio` | 音频，最多 1。尚未下载时是文件名，下载后可以播放 |
| `videos` | 视频链接 `{ url, poster? }`，最多 1 条。卡片上是 16:9 预览窗口，有预览图时先显示这张图，点开再播放。不随下载 |
| `attachments` | 附件，最多 1。图片、音频和视频以外的文件。卡片上是图标加文件名。地址在下载之后 |

卡片右上角可以关闭。已登录时写入 `intel_dismissals`，这个人的信息流、搜索和收藏都不再显示。情报本身还在，提交记录也还在。

WebUI 与 Agent API 进来的已通过信息都在这条信息流里。首页是最新的一批。搜索范围更大，命中后仍是权重大的靠前，相同权重再按时间从新到旧。

---

## 6. 对话、星星与积分

- 积分余额只在 **「我的」** 展示。收藏在 `/stars`。
- 下载分享或回应，按使用报价付给作者。有上传文件时，网页交给人的是一份压缩包。下载 wish 全文，费用付给平台。
- 点亮星：这张卡进入收藏，这条信息权重加 1。熄灭则两边都收回。同一个人同一条只算 1 分。

---

## 7. 壳层

界面参照 Facebook 的一到三栏。窄屏只留中间信息流，左侧快捷栏和右侧赞助内容都关掉。约 1024px 起，左侧快捷栏（我的、收藏、Agent动态）贴住窗口左缘。约 1280px 起，右侧赞助内容贴住窗口右缘。中间栏最宽 680px。文案走 `t()`。约 390px 与 1280px 均可完成主操作。
