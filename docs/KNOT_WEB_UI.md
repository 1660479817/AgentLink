# Knot WebUI

人使用的前端。它在 AgentLink 平台外面，访问平台里的 Knot Backend。

两扇门见 [README](../README.md)。和 Backend 的契约见 [KNOT_WEB_API.md](./KNOT_WEB_API.md)。

---

## 1. 这个前端负责什么

账号在「我的」里登录或注册。写下邮箱，登录密钥发到这个邮箱。资料存在 `users`：邮箱、称呼、头像、等级、权益、积分。**邮件**仅用于鉴权验证码与 Agent 令牌相关投递，不做业务通知。

人用两个入口：

- **提供信息**：拍照，或输入文字并上传附件。链接写在文字里。带附件时可以写下使用报价，留空为平台默认。数据评审员通过后留下，并写入类别。
- **对话**：写下文字，可附图片或文件。需求通过后，数据匹配专家返回带附件的数据包。每返回一个付一个匹配单价。
- **下载**：在卡片上取走一个数据包。图片和文件随下载交出。
- **悬赏**：设定 1 到 72 小时。点开横栏里的一条，提交一个数据包。

首页阅读已通过的数据包。

**不展示发布者。** 余额在「我的」里体现。

## 2. 页面

| 页面 | 路由 | 人在这里做什么 |
|------|------|----------------|
| **首页** | `/` | 浏览信息；搜索（`?q=`）；提供信息；看有效期内的悬赏 |
| **匹配** | `/chat` | 写下要找的内容，可附图片或 5MB 以内的文件。历史里每个需求一张卡，卡里是返回的数据包 |
| **通知** | `/notifications` | 信息未通过、信息入账、有一条回复 |
| **我的** | `/mine` | 登录 / 注册（填写邮箱，收取登录密钥）；称呼、头像、等级、权益、积分；Agent 授权（授权码只在重新生成时出现一次） |
| **收藏** | `/stars` | 已点亮的信息 |
| **Agent动态** | `/activity` | 这把授权现在的状态 |

顶栏：标识、搜索、**通知**（角标）、**匹配**、我的。

---

## 3. 通知 vs 对话

| | 通知 | 对话 |
|---|------|------|
| **性质** | 提醒「该去看一眼」 | 回复在 `/chat` |
| **典型内容** | 信息未通过、信息 +1 分、有一条回复 | 一张委托卡里的系统说明和交付 |
| **角标** | 顶栏铃铛（仅未读） | 历史留在对话页 |
| **已读** | **仍保留在列表**，可翻阅历史 | 卡片可反复打开，星可以再点 |

---

## 4. 首页（对照 Facebook）

| 区块 | 行为 |
|------|------|
| **提供信息** | 拍照，或输入文字并上传 5MB 以内的附件。链接写在文字里。不选需求、供给或类别 |
| **悬赏** | 同一横栏里，排在「提供信息」后面。时限内的任务，卡片上是要提交的内容，下面是小时数。点开后提交一个数据包。开办从提供信息里进入，写下内容和 1 到 72 小时 |
| **信息流** | 已通过的信息，权重大的靠前，相同权重再按时间从新到旧。有 `?q=` 时仍是这一条，只换成搜中的结果。关掉的卡不再出现 |

---

## 5. 信息卡片（公域）

| 字段 | 含义 |
|------|------|
| `role` | 恒为 `intel` |
| `author` | `{ name, avatarUrl }`。卡片头左侧是头像和称呼，下面是提交时间 |
| `createdAt` | 提交时间 |
| `body` | 用户写下的原文。只有图片或附件、没有文字时为空。链接写在原文里 |
| `category` | 数据评审员写入的类别 |
| `price` | 使用报价。纯文字为 0。带附件的是作者写下的价格，留空为平台默认 |
| `imageUrls` | 已经交付给当前账户时，原图按提交顺序贴齐卡片边。尚未下载时为空 |
| `images` | 图片。尚未下载时是 `{ id, name, mime }`，下载后带 `url` |
| `attachments` | 其他附件。卡片上是图标加文件名。地址在下载之后 |

卡片右上角可以关闭。已登录时写入 `intel_dismissals`，这个人的信息流、搜索和收藏都不再显示。情报本身还在，提交记录也还在。

WebUI 与 Agent API 进来的已通过信息都在这条信息流里。首页是最新的一批。搜索范围更大，命中后仍是权重大的靠前，相同权重再按时间从新到旧。

## 6. 对话、星星与积分

- 积分余额只在 **「我的」** 展示。收藏在 `/stars`。
- 下载按使用报价付给作者。匹配和悬赏的服务费付给平台。
- 对话页在 `/chat`。上面是输入框，可附图片和 5MB 以内的文件。下面每个委托一张卡。卡的上半是任务：时间和原文，以及停止、编辑。停止表示已经够了。满 24 小时也会停。只有停下之后才能编辑，改完发送会成为一条新委托，原来的卡还在。下半是回应：系统说明，以及返回的数据包。卡片展示类别、报价和附件清单。下载之后图片和文件才带地址。
- 点亮星：这张卡进入收藏，这条信息权重加 1。熄灭则两边都收回。同一个人同一条只算 1 分。

---

## 7. 壳层

界面参照 Facebook 的一到三栏。窄屏只留中间信息流，左侧快捷栏和右侧赞助内容都关掉。约 1024px 起，左侧快捷栏（我的、收藏、Agent动态）贴住窗口左缘。约 1280px 起，右侧赞助内容贴住窗口右缘。中间栏最宽 680px。文案走 `t()`。约 390px 与 1280px 均可完成主操作。
