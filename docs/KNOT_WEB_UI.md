# Knot WebUI

人使用的前端。它在 AgentLink 平台外面，访问平台里的 Knot Backend。

两扇门见 [README](../README.md)。和 Backend 的契约见 [KNOT_WEB_API.md](./KNOT_WEB_API.md)。

---

## 1. 这个前端负责什么

账号在「我的」里登录或注册。写下邮箱，登录密钥发到这个邮箱。资料存在 `users`：邮箱、称呼、头像、等级、权益、积分。**邮件**仅用于鉴权验证码与 Agent 令牌相关投递，不做业务通知。

人用两个入口：

- **提供信息**：拍照，或输入文字并上传附件。关于自己或关于别人都是一条信息。knot-intel 判断通过后奖励 1 积分。违规不留下。页面上不写「情报」。
- **对话**：写下文字，可附图片或文件。knot-demand 按一条信息一张卡交回。引用几条，就扣几个同一单价。库里没有的，先问 knot-seek；能补上的会进库存，再出现在卡片里。

首页仍可浏览已通过的信息。自己翻是时间成本。委托找才扣积分。

**不展示发布者。** 余额在「我的」里体现。

## 2. 页面

| 页面 | 路由 | 人在这里做什么 |
|------|------|----------------|
| **首页** | `/` | 浏览信息；搜索（`?q=`）；提供信息 |
| **对话** | `/buy` | 像聊天一样写下文字，可附图片或 5MB 以内的文件；回复是卡片，历史在下面 |
| **通知** | `/notifications` | 信息未通过、信息入账、有一条回复 |
| **我的** | `/mine` | 登录 / 注册（填写邮箱，收取登录密钥）；称呼、头像、等级、权益、积分；收藏；Agent 授权入口 |
| **Agent 授权** | `/delegate` | 发放/收回 Personal Agent 凭证 |

顶栏：标识、搜索、**通知**（角标）、**对话**、我的。

---

## 3. 通知 vs 对话

| | 通知 | 对话 |
|---|------|------|
| **性质** | 提醒「该去看一眼」 | 回复在 `/buy` |
| **典型内容** | 信息未通过、信息 +1 分、有一条回复 | 一张张卡片，以及引用了几条、扣了多少 |
| **角标** | 顶栏铃铛（仅未读） | 历史留在对话页 |
| **已读** | **仍保留在列表**，可翻阅历史 | 卡片可反复打开，星可以再点 |

---

## 4. 首页（对照 Facebook）

| 区块 | 行为 |
|------|------|
| **提供信息** | 拍照，或输入文字并上传 5MB 以内的附件。不选需求、供给或类别 |
| **信息流** | 已通过的信息，先按权重从高到低，相同再按时间从新到旧。有 `?q=` 时仍是这一条，只换成搜中的结果 |

---

## 5. 信息卡片（公域）

| 字段 | 含义 |
|------|------|
| `role` | 恒为 `intel` |
| `body` | 用户写下的原文。只有图片、没有文字时为空 |
| `imageUrls` | 用户上传的原图，按提交顺序。没有上传则为空 |
| `attachments` | 文字输入带上的附件。图片同时出现在 `imageUrls`。其他文件是链接 |

WebUI 与 Agent API 进来的已通过信息都在这条信息流里。首页是权重高的一批。搜索范围更大，命中后仍先按权重、再按时间。

---

## 6. 对话、星星与积分

- 积分余额只在 **「我的」** 展示。收藏也在 **「我的」**。
- 提供一条并通过，奖励 1 积分。
- 对话页在 `/buy`。上面是输入框，可附图片和 5MB 以内的文件。回复是卡片，一条信息一张。下面是历史。按张扣同一个单价，页面上不写成买卖。
- 点亮星：这张卡进入收藏，这条信息权重加 1。熄灭则两边都收回。同一个人同一条只算 1 分。
