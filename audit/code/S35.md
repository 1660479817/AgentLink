# S35 — xknot.si/web 联邦门户主组件

## 已读清单
| 文件 | 行数 | 结论 |
|---|---|---|
| xknot.si/web/src/App.vue | 1269 | 8 issues |

XSS / 开放跳转结论：**外部输入没有注入面，也没有可被控制的跳转目标。** 全文件没有 `v-html`、`innerHTML`、`document.write`、`window.open`，也没有读写 `location`（`rg 'v-html|innerHTML|window\.open|location\.'` 在 `xknot.si/web/src` 下零命中）。实例自述的 `name`/`intro`/`tags` 只经文本插值上屏（`App.vue:96` → `NodeCard.vue:154`、`NetworkMap.vue:301/304/330`），Vue 自动转义。所有动态地址都过上游白名单：`logo` 走 `normalizeAsset` 的 `https://` 前缀判定（`snapshot.js:16-22`），橱窗 `url` 走 `httpsUrl()` 的 `new URL().protocol === "https:"`（`cards.js:28-35`），站点 `url` 由中枢签发、校验时必须是 `https://<label>.xknot.si` 且不许带 userinfo（`profile-schema.mjs:57-64`、`checkIssued`），申请表里调用方传的 `domain` 直接被拒（`validate.mjs:82`）。站内唯一的拼接链接 `:href="`/${locale}/`"` 用的是 `isLocale()` 白名单后的值（`main.js:10-11`）。残余风险只有两条，见 S35-08 与末尾「需运行验证」：自述名称的不可见字符可做身份伪装；`logo` 允许任意 https 主机，门户以 `<img>` 直接装载（访客 IP 与体积不受控）。
