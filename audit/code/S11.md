## 发现

本切片没有 `src/routes/*`；端点鉴权按调用方读过 `src/routes/admin.js`、`src/routes/web.js`、`src/routes/agent.js` 核对，问题归到它们调用的实现模块。`/api/admin/*` 的准入（`isIntranetAddress` + `bearerToken` + `tokensMatch`/`handoff.verifyAdminSession`）逐个端点看过，没有发现可绕过的路径：`/handoff/claim` 自带内网检查，其余端点全在 `router.use` 之后；按 id 取他人资源的水平越权没有找到（`/api/admin/posts/:id/remove` 是管理面，`/api/web/intel/:id/close` 另有 `isOwnerAccount`）。`createIntel`/`downloadPacket`/`lookRequest` 一类按 id 的操作依赖 `grants`/`packet_downloads` 判定，未发现只判登录不判归属的分支。
