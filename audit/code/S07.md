## 附注（跨片，S08 `admin.js` 的线索，不计入本片 ID）

- `admin.js:19` `CREDENTIAL_KEY` 落 `localStorage`（30 天管理凭据，`handoff.js:20` 的 `ADMIN_TTL_MS` 印证）；同 origin 的 WebUI 一旦出现 XSS 就能把它读走，本页 0 注入点并不代表整站 0 注入点。
- `logout()`（`admin.js:461-465`）只清 `sessionStorage`/`localStorage`，不重置 `state.agentToken`，也不清 `#token-value`；退出后 Agent 授权码明文还留在隐藏的 DOM 与内存里，直到下一位 Agent 被选中。
- `retireAgent`（`admin.js:1587-1591`）用 `window.prompt` 且预填 `users.retireDefault`，连按回车即可停用 Agent 并作废其授权码，没有二次确认。
- `loadJoinApplication`（`admin.js:2355-2362`）除 401 外吞掉所有错误并把 `state.joinApplication` 置空，网络一抖「已提交的申请」就从卡片上消失，再提交会被中枢判重。
- `el("a", { href: application.caseUrl })`（`admin.js:2535`、`2641`）对外部返回的 URL 不校验 scheme；`imageSource`（`admin.js:1907-1913`）放行任意 `https:`/`//` 作为 `img src`。
